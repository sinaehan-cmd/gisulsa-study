# ② 쉽게 먼저

회사가 돈을 벌려면 먼저 직원 역량과 시스템을 개선하고, 업무가 빨라지고, 고객이 만족하고, 매출이 증가해야 한다. BSC는 이 연결을 관리한다. 투자분석은 그 시스템에 돈을 써도 되는지 판단하고, 투자평가는 돈뿐 아니라 고객·업무·위험까지 평가한다. 전략적 기업경영은 이 모든 활동을 전략과 예산, 실행, 성과 피드백으로 연결한다.  
\[보충\] 전체 흐름: 환경분석 → 전략수립 → 목표·KPI(BSC) → 투자대안 분석 → 예산·실행 → 성과평가 → 전략 개선. 각 기법은 서로 대체하는 것이 아니라 역할이 다르다.

# ③ 정의 핵심어

BSC: 조직의 전략목표 달성을 위해 재무·비재무 성과를 4관점으로 균형 관리하는 체계.  
전략지도: 전략목표 간 인과관계를 시각화하여 전략 실행을 지원하는 도구.  
IT-ROI: IT 투자비용 대비 창출된 순편익을 비율로 측정하는 투자성과 평가기법.  
IT 투자분석: IT 투자 의사결정을 위해 대안별 비용·편익·위험을 분석하는 기법.  
IT투자평가: IT 투자의 타당성과 성과를 정량·정성 지표로 종합 평가하는 활동.  
전략적기업경영(SEM): 기업의 전략목표 달성을 위해 전략·계획·실행·성과관리를 통합하는 경영체계.

# ④ 답안 뼈대 \[보충: 학원 해설 원문 미검증, 기출 요구와 일반 원리 기반\]

## A. BSC(최상) — 3분 인출 후 누락만 보충

1교시 표 행: 재무(매출·수익률), 고객(만족도·유지율), 내부 프로세스(처리시간·오류율), 학습과 성장(역량·교육), 전략지도(목표 간 인과), KPI(측정지표·목표값).  
구성도: 학습·성장 → 내부 프로세스 → 고객 → 재무. 화살표는 인과 가설이며 측정으로 검증한다. 전략목표 → KPI → 목표값 → 실행과제 연결.  
IT 사례: 운영자 자동화 역량 향상 → 배포 소요시간 감소 → 서비스 만족도 향상 → 운영비 절감. 목표와 KPI를 구분(예: 배포 효율 향상 / 평균 배포시간).  
2교시 목차: Ⅰ BSC 개요 및 4관점 / Ⅱ 전략지도 구성 및 인과관계 / Ⅲ IT 부문 적용 방안 및 성과관리. 실제 아침 답안은 본문 읽기 전에 작성.

## B. IT-ROI·IT 투자분석(상) — 전날 오답 확인

ROI=(총편익−총비용)/총비용×100%. 비용 1억, 편익 1.5억 → 50%. 순편익이 주어진 경우 다시 비용을 빼지 않는다.  
비교표(행: 기법 \| 판단 기준 \| 시간가치 \| 한계)  
ROI \| 투자비 대비 순편익률 \| 단순 ROI 미반영 \| 기간·현금흐름 차이 무시  
NPV \| Σ CFt/(1+r)^t − I0, 양수이면 타당 \| 반영 \| 할인율·추정치 의존  
IRR \| NPV=0이 되는 할인율, 요구수익률 초과 \| 반영 \| 비정상 현금흐름 복수 해 가능  
PP \| 초기 투자금 회수까지 기간 \| 단순 PP 미반영 \| 회수 이후 편익 무시  
TCO \| 도입·운영·유지·폐기 전 생애 비용 \| 방법에 따라 할인 가능 \| 편익 자체는 평가하지 않음  
\[보충\] 1교시 IT-ROI 표: 목적, 비용, 편익, 산식, 평가 시점, 한계. 사전은 예상 비용·편익, 중간은 진척·비용 통제(EVM 보조), 사후는 실현 편익·KPI 확인. EVM은 ROI 자체의 산식이 아니다.  
129회형 2교시 목차: Ⅰ 프로세스(목표·범위 → 대안 → 비용·편익 추정 → 경제성·위험 분석 → 선정·사후검증) / Ⅱ 프레임워크(재무·비재무·전략 적합성·위험·실행가능성) / Ⅲ 분석 방법론(위 5기법 비교, 민감도 분석 보조).

## C. IT투자평가(중) — 새 학습

정량·정성 평가표 6행: 투자비(구축·운영비), 재무편익(매출·절감액), 경제성(NPV·IRR), 전략적합성(사업목표 연계), 서비스 품질(고객 만족·업무 개선), 위험·실행가능성(보안·기술·조직 역량). 정성 항목도 점수화하거나 KPI로 계량할 수 있다.  
구성도: 투자대안 → 정량평가 \+ 정성평가 → 종합판단 → 투자선정 → 사후 성과 검증.  
125회형 목차: Ⅰ IT 투자평가 개요 / Ⅱ 정량적 및 정성적 평가 항목 및 내용 / Ⅲ 기업의 BSC 전략맵(문제의 배송 사례 적용). 

## D. 전략적기업경영(중) — 새 학습

\[보충\] SEM 구성요소 예시: 전략관리(BSC), 사업계획·예산(BPS), 성과측정·분석(BPM), 경영정보 통합(BI/DW), 시나리오·의사결정 지원, 실행·피드백. 제품별 구성 명칭은 다를 수 있으므로 학원 해설 확인 필요.  
구성도: 외부·내부 환경 → 전략목표 → 사업계획·예산 → 실행 → 성과측정 → 개선(전략으로 환류). 데이터 통합·경영정보는 전 단계 지원.  
131회형 목차: Ⅰ 전략적 기업경영의 정의 / Ⅱ 전략적 기업경영의 구성요소 / Ⅲ 전략적 기업경영의 구축 방안 및 구축 절차. 구축 방안: 전략과 KPI 정렬, 데이터 표준화, 책임·권한, 단계적 도입. 절차: 현황 진단 → 전략·지표 설계 → 데이터·시스템 구축 → 시범운영 → 확산·개선.

## E. 여유 있을 때만(하)

AHP: 복수 평가기준의 상대 중요도를 쌍대비교하여 대안 우선순위를 산정하는 의사결정 기법. 계층구조→쌍대비교→가중치→일관성 검증→종합순위.  
TAM-SAM-SOM: 전체 잠재시장→서비스 가능 시장→현실적 확보 가능 시장. 포함관계 TAM⊇SAM⊇SOM.  
화이트 레이블 마케팅: 공급자의 제품·서비스를 다른 기업이 자체 브랜드로 판매하는 방식. 빠른 출시·비용 절감 vs 차별화·공급자 종속 위험.

# ⑦ ⛔ 여기까지

BSC·ROI·투자분석은 이미 K2이므로 반복 강의 금지. 오답 인출 후 투자평가·SEM으로 이동. AHP 고유벡터 계산, IRR 수치해법, 복잡한 재무모형, 특정 SEM 제품 세부 모듈은 시험 밖. 하 토픽은 여유 있을 때만 한 줄.

# ⑧ 헷갈리는 짝

BSC vs 전략지도: 성과관리 체계 vs 전략목표 인과 시각화.  
ROI vs IRR: 순편익 비율 vs NPV를 0으로 만드는 할인율.  
NPV vs TCO: 순현재가치(편익 포함) vs 생애 비용.  
투자분석 vs 투자평가: 대안 타당성 분석 중심 vs 정량·정성 종합 및 사후성과 평가.  
SEM vs BSC: 전사 전략경영 통합 vs 성과관리 도구.  
인수인계: 11/24 BSC·ROI·투자분석 실제 구술 K2, 백지 미실시. 내일 먼저 아침 BSC 백지 결과 확인, ROI 산식과 NPV 초기비용을 짧게 인출하고 새 토픽 진행. 교재 생성 자체로 학습 확인 수준을 변경하지 않음.
