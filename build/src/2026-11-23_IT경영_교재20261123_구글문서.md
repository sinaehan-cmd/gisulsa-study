② 쉽게 먼저 — 하나의 AI 상담 도입 사례  
회사의 상담 대기시간이 길고 인건비가 높다.  
PEST: 규제·경기·비대면 선호·AI 기술 같은 거시 외부환경을 본다.  
3C: 고객은 24시간 응대를 원하고, 경쟁사는 챗봇을 쓰며, 자사는 고객 데이터는 많지만 AI 인력이 부족하다.  
SWOT: 내부 강점·약점과 외부 기회·위협을 결합해 전략을 도출한다.  
가치사슬: 판매·서비스 등 활동별 가치·비용·병목을 찾는다.  
BPR: 모든 상담을 사람이 하던 업무를 AI 1차 응대와 복잡한 문의의 상담원 연결로 근본 재설계한다.  
ISP: 이 혁신을 지원할 IT 전략·목표 시스템·투자 및 이행 로드맵을 수립한다.  
이것은 이해를 위한 연결 그림이며 모든 기업이 이 순서로 수행해야 하는 고정 절차는 아니다.

③ 기술사 정의 핵심어  
ISP: 조직의 경영목표 달성을 위해 정보화 현황을 분석하고 목표모델과 이행계획을 수립하는 전략계획 기법.  
  핵심: 경영전략 연계 / 정보화 현황 / 목표모델 / 통합이행계획.  
BPR: 업무 성과의 획기적 개선을 위해 기존 업무 프로세스를 근본적으로 재설계하는 경영혁신 기법.  
  핵심: 근본적 재고 / 획기적 개선 / 업무 프로세스 / 비용·품질·서비스·속도.  
PEST: 기업 전략 수립을 위해 정치·경제·사회·기술의 거시 외부환경을 분석하는 기법.  
3C: 경쟁전략 수립을 위해 고객·경쟁사·자사의 시장과 역량을 분석하는 기법.  
SWOT: 전략적 대안 도출을 위해 내부 강점·약점과 외부 기회·위협을 분석하는 기법.  
가치사슬: 기업 활동을 주활동과 지원활동으로 분류해 가치 창출과 경쟁우위 원천을 분석하는 기법.

④ 답안 뼈대(1교시 표 행 이름 / 2\~4교시 목차)  
A. ISP와 BPR — 131회 2교시형(25점)  
Ⅰ. 개요: ISP·BPR 정의, 경영전략과 업무혁신의 연계 필요성  
Ⅱ. ISP와 BPR 수행절차·비교  
  ISP: 환경분석 → 현황분석 → 정보화 비전·전략 → 목표모델 → 통합이행계획  
  \[보충\] BPR 일반적 예시: 혁신 목표·대상 선정 → As-Is 업무분석 → 병목·KPI 파악 → To-Be 프로세스 재설계 → 실행·변화관리·성과평가. 단일 공식 절차라고 단정하지 않음.  
  비교표: 구분 / 목적 / 분석 대상 / 관점 / 범위 / 주요 활동 / 산출물 / 성과지표 / 연계  
  ISP=IT 전략·목표모델·투자 로드맵, BPR=업무 혁신·To-Be 프로세스.  
Ⅲ. 상호 보완 활용: 경영목표·환경 분석 → 업무 병목(BPR) → 개선된 업무 요구사항 → ISP 목표모델·투자 우선순위·이행계획 → KPI 평가.  
  사례: AI 상담 대기시간 단축·고객만족 향상·운영비 절감. 비효율을 그대로 자동화하는 위험 주의.

B. PEST·3C·SWOT — 133회 3교시형(25점)  
Ⅰ. 경영환경분석 개요  
Ⅱ. 세 기법의 특징·적용 조건·분석 방법  
  PEST 표: P 정치·정책 / E 경제·시장 / S 사회·문화 / T 기술·혁신.  
  3C 표: Customer 고객 니즈 / Competitor 경쟁사 전략 / Company 자사 역량.  
  SWOT 2×2: S 강점, W 약점(내부) / O 기회, T 위협(외부). 전략 SO·ST·WO·WT.  
  비교표: 구분 / 분석 대상 / 내·외부 범위 / 구성요소 / 적용 조건 / 분석 방법 / 산출물 / 장점 / 한계.  
Ⅲ. 적용 사례와 ISP 연계: PEST로 거시 변화, 3C로 경쟁 구도·자사 역량, SWOT로 전략 대안, 가치사슬로 내부 강약점 근거 확보.  
  3C에는 자사(내부)도 포함한다. SWOT는 네 칸만 적지 말고 전략 조합까지.

C. 가치사슬 — 124회 1교시형(10점)  
정의 \+ 포터 가치사슬 구성도 \+ 시스템 비교표(구분 칸 포함 6줄 이상).  
  지원활동 4: 기업 하부구조 / 인적자원관리 / 기술개발 / 조달  
  주활동 5: 투입물류 → 운영(생산) → 산출물류 → 마케팅·판매 → 서비스 → 마진  
  비교표: 구분 / 목적 / 지원 가치활동 / 주요 데이터 / 효과 / 적용 사례.  
  ERP=전사 자원 통합(주·지원활동 전반), SCM=공급망·물류(조달·투입·산출물류), MES=생산현장(운영), CRM=고객관계(마케팅·판매·서비스).  
  주의: 구매 계약은 지원활동 '조달', 실제 입고·보관은 주활동 '투입물류'. ERP는 한 활동에만 한정되지 않는다.  
  마진=총가치−가치활동 수행 총비용.  
  129회 반도체 산업 가치사슬은 설계→제조→후공정 등 산업 전체 단계로 분석. 포터 주5·지원4와 혼동 금지.

D. 아침 ISP·ISMP 백지(전날 학습 연계)  
25분 동안 아래 ⑤를 가리고 Ⅰ 정의·목적 Ⅱ 단계별 활동·산출물 비교표 Ⅲ 적용 차이 목차와 그림을 직접 작성.  
  ISP=전사 정보화 전략·투자 방향, ISMP=특정 정보시스템 구축의 상세 요건·이행방안.  
  특히 ISP 3단계 '정보화 비전·전략' vs ISMP 3단계 '정보기술 요건분석' 혼동 주의.  
  공통가이드 6판 세부 개정점은 검증 없이 만들지 않음.

⑧ 헷갈리는 짝  
ISP vs ISMP: 전사 전략·목표모델 vs 특정 시스템 상세 요건·이행방안.  
ISP 3단계 vs ISMP 3단계: 정보화 비전·전략 vs 정보기술 요건분석.

3C vs SWOT: 시장·경쟁 구도 파악 vs 강약기회위협 종합 및 전략 대안.  
가치사슬 vs BPR: 가치·비용 분석 틀 vs 업무 혁신.  
기업 가치사슬 vs 산업 가치사슬: 기업 내부 주5·지원4 vs 산업 단계·참여자.  
조달 vs 투입물류: 구매·계약(지원) vs 입고·보관(주활동).  
SCM(공급망관리) vs SCM(형상관리): 약어가 같지만 경영에서는 공급망.
