# 핵심암기 모음 — IT경영 (BSC · IT-ROI · IT 투자분석 · IT 투자평가)

출처: 구글 문서 '핵심암기 모음' IT경영 구역 발췌 (2026-11-25 기준)
## BSC (11/24)
정의: 재무·비재무 관점의 전략목표와 성과지표를 균형 있게 연계하는 성과관리 체계
흐름: 학습·성장 → 내부 프로세스 → 고객 → 재무 (전략지도의 인과)
흐름
	핵심어
	4관점
	재무 · 고객 · 내부 프로세스 · 학습과 성장
	전략지도
	학습·성장 → 내부 프로세스 → 고객 → 재무 인과관계로 전략목표를 연결
	두음: 재고내학 (확정)
꼭 외울 것: 재무/비재무 균형 + 전략목표·성과지표 연계 + 전략지도 인과
## IT-ROI (11/25)
정의: IT 투자 타당성·효율성·효과성을 지속 평가하는 성과관리 모델
흐름: 사전 → 중간 → 사후 → 피드백
흐름
	핵심어
	평가 단계
	사전 타당성·중간 효율성·사후 효과성
	측정지표
	IT 투자성과·IT 투자비용
	

두음: 확정 없음
꼭 외울 것: 사전 타당성·중간 효율성·사후 효과성, 투자성과·투자비용 (ITPE 128회 1교시 2번)
## IT 투자분석 (11/25)
정의: 기업목표 달성 및 경제적 기여도를 사업적 관점에서 분석하는 기법
흐름: IT 기획 → 투자 → 구축 → 업무 프로세스 → 업무 성과 → 경영 성과
흐름
	핵심어
	프로세스
	기획·투자·구축·업무 프로세스·업무 성과·경영 성과
	프레임워크
	평가·시행추진·성과추진·분석기법 (BSC·CSF·KPI)
	방법론
	실물옵션(블랙숄즈·이항·몬테카를로) / 비용편익(ROI·NPV·IRR·PP) / 다중분석(재무·사업·기술·위험, IO·IE)
	일반론 구분
	목표·대안·비용편익·경제성위험·선정은 사전 의사결정 절차
	

두음: 확정 없음
꼭 외울 것: 6단계·4영역·3방법론 (ITPE 129회 4교시 5번). IRR은 요구수익률 초과 기준.
## IT 투자평가 (11/25)
정의: IT 투자 타당성과 성과를 정량·정성 지표로 종합 평가하는 활동
흐름: 정량·정성 평가 → 종합 판단
흐름
	핵심어
	정량
	투자비용·재무편익·경제성
	정성
	전략적합성·서비스품질·위험 및 실행가능성
	

두음: 확정 없음
꼭 외울 것: TCO는 비용, ROI·NPV·IRR·PP는 경제성. 125회 ITPE 해설 미발견, 교재 기준.
