# 2026-11-25 IT경영 — BSC(균형성과기록표)·전략지도

- 학습일: 2026-11-25 (수, Asia/Seoul)
- 과목: IT경영
- 학원 토픽: 균형 성과 기록표 (Balanced Score Card) — 토픽 59행, 최상
- 범위: BSC 4관점, 전략지도와 인과관계, IT 부문 적용

## 1. 쉽게 먼저

회사가 고객 만족과 매출을 높이려면 돈만 보지 말고 직원의 역량, 업무 방식, 고객 반응, 재무 성과를 함께 봐야 한다. 예를 들어 IT 교육에 투자해 운영 역량을 높이면 업무가 빨라지고 서비스 품질이 좋아져 고객 만족 및 비용·수익 개선으로 이어질 수 있다. BSC는 이러한 전략목표를 네 관점에서 균형 있게 관리한다.

## 2. 정의

**BSC:** 조직의 전략목표 달성을 위해 재무·비재무 성과를 4관점으로 균형 있게 관리하는 성과관리 체계.

**전략지도(Strategy Map):** 관점별 전략목표의 인과관계를 시각화하여 전략 실행 경로를 표현하는 도구.

## 3. 구성도·흐름

```text
[학습과 성장] 직원 역량·IT 자동화 교육
       ↓ (업무 수행 능력 강화)
[내부 프로세스] 업무 혁신·처리시간 단축·오류 감소
       ↓ (서비스 품질 개선)
[고객] 만족도·서비스 신뢰도 향상
       ↓ (비용 절감·매출 확대에 기여)
[재무] 운영비 절감·매출 및 수익성 개선
```

- 전략지도 화살표는 **전략목표 사이의 인과 가설**을 표현한다. 관점의 배열만 외우는 것이 아니라 각 연결의 근거를 KPI로 점검한다.
- 실행 연결: **전략목표 → KPI(측정지표) → 목표값 → 실행과제 → 성과점검·개선**.

## 4. 핵심 표

| 구분 | 핵심어·IT 적용 예시 |
|---|---|
| 학습과 성장 | 인적 역량·지식·IT 교육, 자동화 역량 / 교육 이수율 |
| 내부 프로세스 | 업무 효율·품질·혁신 / 처리시간·배포 소요시간·장애 복구시간(MTTR) |
| 고객 | 서비스 품질·만족·유지 / 고객 만족도·SLA 준수율 |
| 재무 | 비용·수익·투자 성과 / IT 운영비 절감률·수익성 |
| 전략지도 | 학습과 성장 → 내부 프로세스 → 고객 → 재무, 목표 간 인과관계 시각화 |
| 성과관리 | 전략목표(달성하고자 하는 상태)와 KPI(달성 정도를 재는 지표) 구분, 목표값·실행과제 연결 |

## 5. 두음(확정만)

- **재고내학** = 재무·고객·내부 프로세스·학습과 성장 (공동 장부 `두음` 탭에서 확인한 학원 확정 두음).
- 전략지도 설명 흐름: **학습·성장 → 내부 프로세스 → 고객 → 재무** (두음 신규 확정 아님).

## 6. 헷갈리는 짝

| 구분 | 차이 |
|---|---|
| BSC vs 전략지도 | BSC: 네 관점의 전략성과관리 체계 / 전략지도: 전략목표 간 인과관계 도식 |
| 전략목표 vs KPI | 목표: 무엇을 개선할 것인가(예: 서비스 품질 향상) / KPI: 얼마나 달성했나(예: SLA 준수율) |
| 재무 vs 비재무 | 재무: 비용·매출 등 결과 지표 / 비재무: 고객·프로세스·역량 등 미래 성과의 선행 요인 |
| BSC vs IT-ROI | BSC: 전략목표와 재무·비재무 성과의 균형 관리 / ROI: 투자비 대비 순편익 비율 산정 |
