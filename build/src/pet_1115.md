# 2026-11-15 정보보안 — PET·동형암호·연합학습

> 학습 방식: GPT | 시험: 정보관리기술사·컴퓨터시스템응용기술사 | 학원 중요도: PET **최상**, 동형암호 **상**
> 학습 범위: PET, 동형암호, 차분 프라이버시, 합성데이터, MPC, 연합학습, 영지식증명, TEE, 개인정보 보호 적용 사례
> 확인 수준: PET 전체 **학습 중(수준 1 기준)**. 동형암호·차분 프라이버시·합성데이터 **원리·한계·보호 시점은 말로 독립 인출 성공(부분 영역 수준 2 근거)**. 백지 작성 없음.

## Ⅰ. 학습 개요 및 출제

- PET = Privacy-Enhancing Technologies(개인정보 보호 강화기술). 단일 알고리즘이 아닌 **기술의 총칭**.
- 134회·138회 PET 관련 기출: 개념·등장 배경·주요 기술 분류·핵심 기술·적용 사례, **동형암호 vs 차분 프라이버시 vs 합성데이터 상세 비교**. 학원 정리 기준.
- 연관 별도 토픽: 동형암호(125·133회 관련 해설), MPC(133회), ZKP(132회), 가명정보 처리 단계(140회). 별도 심화 답안은 아직 작성하지 않음.
- 오늘은 PET의 기술별 원리·비교·일부 암기 및 인출. PET 4대 분류 전체 독립 인출과 2~4교시 답안 작성은 미완료.

## Ⅱ. 사람말 원리와 정확한 정의

**PET 정의(필수 암기)**: 개인정보 노출 위험을 최소화하면서 데이터의 분석·활용 가치를 유지하기 위한 개인정보 보호 강화기술의 총칭.

**등장 배경(필수)**
1. 기술: AI 학습·빅데이터 분석에 필요한 데이터 수요 확대, 재식별·추론 공격 위험.
2. 법·제도: 개인정보 보호 의무 강화와 합법적인 데이터 활용의 병행 필요.
3. 활용: 기관 간 통계·연구·데이터 결합 및 안전한 공동 분석 수요.

**사람말:** 데이터를 쓰고 싶지만 개인정보를 보여 줄 수 없다. 그래서 ① 데이터를 변형하거나 ② 보호된 상태로 계산하거나 ③ 원본을 옮기지 않고 공동 학습하거나 ④ 사용 주체와 이력을 관리한다.

## Ⅲ. 기술사 답안 핵심

### 1. PET 4대 분류 — 학원 해설 명칭 그대로(필수 암기)

| 분류 | 목적/역할 | 학원 해설의 대표 기술 |
|---|---|---|
| **① 데이터 난독 처리 도구** | 개인 식별 위험을 줄이도록 데이터·공개 결과를 변형·제어 | 차분 프라이버시(DP), 합성데이터(SDG), 영지식증명(ZKP) |
| **② 암호화된 개인정보 처리** | 보호된 입력을 활용해 계산 | 동형암호(HE), 신원 기반 암호(IBE), 안전한 다자간 연산(MPC/SMPC), TEE |
| **③ 연합 및 분산 분석** | 원본 데이터를 중앙으로 모으지 않고 공동 분석·학습 | 연합학습(FL), 분산 분석 |
| **④ 데이터 책임 도구** | 사용 규칙, 권한, 추적, 정보주체 통제 관리 | 책임 시스템, 개인정보 관리 시스템 |

※ 분류명은 **학원 해설 기준**. ZKP와 TEE의 암호학적 기술 성질을 엄격히 따져 보았을 때 ①·② 명칭만으로 모든 구현을 설명하는 것은 아님. **「데이터 책임 도구」 세부 기능은 설명만 들었고 실제 인출하지 않음.**

| 기술 | 정의·원리 | 활용 | 한계/주의 |
|---|---|---|---|
| **동형암호(HE)** | 암호문을 복호화하지 않고 연산, 결과를 복호화하여 평문 연산에 대응하는 값 획득 | 암호화 데이터 위탁 통계·분석 | 높은 CPU 연산 오버헤드, 암호문 팽창, 잡음 관리 |

| **안전한 다자간 연산(MPC)** | 참여자가 비밀 입력을 공개하지 않고 공동 결과 계산 | 기관 간 비밀 통계, 중복 사기 계좌 수 분석 | 통신·계산 오버헤드, 구현 복잡성 |

| **TEE** | 하드웨어 기반 격리 실행 영역에서 처리 중인 데이터(Data in Use)를 보호 | 기밀 컴퓨팅, 클라우드 보호 VM·AI 추론 | 구현별 위협 모델 차이, 사이드채널·펌웨어 취약점 |
| **가명처리** | 추가 정보 없이는 개인을 식별할 수 없도록 식별 정보 처리 | 통계·과학적 연구 등 | 추가정보 결합 시 재식별 가능; 익명정보와 다름 |

### 4. 동형암호 상세(별도 '상' 토픽과 연결)

**정의:** 암호문을 복호화하지 않고 산술 연산을 수행할 수 있는 암호기술.

| 유형 | 연산 능력 | 핵심 |
|---|---|---|
| 부분 동형암호 **PHE** | 덧셈 또는 곱셈 등 **특정 종류**의 연산 | Paillier(덧셈), RSA(곱셈) |
| 준동형암호 **SHE** | 덧셈·곱셈 가능하나 연산 **깊이 제한** | 연산하며 잡음 누적 |
| 완전 동형암호 **FHE** | 임의 깊이의 연산 평가 가능 | 부트스트래핑 등으로 잡음 관리 |

- **잡음(Noise)**: 암호문의 수학적 구성과 연산 과정에서 관리할 값. 누적되면 올바른 복호화가 어려워질 수 있음.
- **스쿼싱(Squashing)**: 초기 Gentry FHE 구현의 복호화 회로를 동형 연산으로 처리하기 쉬운 형태로 단순화하는 기법.
- **부트스트래핑(Bootstrapping)**: 평문을 노출하지 않고 동형적으로 복호화 회로를 평가하여 더 작은 잡음을 가진 암호문으로 갱신하는 기법. **모든 현대 FHE 방식에서 스쿼싱을 사용하거나, 매 연산마다 부트스트래핑하는 것은 아님**.
- 주의: **동형암호의 잡음**은 암호문 연산의 정확성을 관리하는 내부 잡음, **DP의 잡음**은 개인정보 보호를 위해 의도적으로 적용하는 확률적 잡음.

### 5. DP(차분 프라이버시) 심화 범위

- **ε(엡실론)**: 개인 한 명의 참여 여부가 출력 확률에 주는 영향을 제한하는 프라이버시 매개변수(예산).
- 같은 조건에서 일반적으로 **ε↓ → 개인정보 보호↑ → 더 많은 잡음/정확도 부담↑**.
- ε은 **잡음 자체가 아님**. 실제 보호는 δ, 데이터 민감도, 여러 번의 질의·예산 누적 등에도 좌우됨.
- PET 현재 범위에서는 **ε 방향성과 상충관계까지 암기**, 확률 부등식·증명은 암기 제외.
- 예시: 정확한 통계를 여러 번 공개하면 개인 1명의 차이가 노출될 수 있으므로 공개 결과의 개인별 영향 제한.

### 6. MPC vs FL vs HE / ZKP / TEE

| 기술 | 구분할 단어 |
|---|---|
| **HE** | 암호문 상태 연산 |
| **MPC** | 다수 비밀 입력의 **공동 계산** |
| **FL** | 기관별 **로컬 AI 학습**, 모델 업데이트 집계 |
| **ZKP** | 내용은 공개하지 않고 **참임만 증명** |
| **TEE** | 하드웨어 격리로 **처리 중 데이터** 보호 |

- MPC의 주요 방식: 비밀분산(Secret Sharing), 가블드 서킷, 망각 전송, 동형암호 기반 프로토콜 등. 세부 유형은 별도 MPC 문제에서 심화.
- MPC와 FL은 병용 가능: FL에서 모델 업데이트에 **안전한 집계(Secure Aggregation)** 적용.
- MCP(Model Context Protocol)와 MPC(Multi-Party Computation)는 **서로 다른 기술**임.
- ZKP 3대 속성 **완전성**(참이면 통과) · **건전성**(거짓이면 속이기 어려움) · **영지식성**(비밀 유출 없이 참임을 증명).
- TEE(Trusted Execution Environment)는 기밀 컴퓨팅의 핵심 구현 요소 중 하나; 보호 위협모델은 SGX/TDX/SEV-SNP 등마다 다름.
- 데이터 저장(Rest): BitLocker/LUKS/TDE / 전송(Transit): TLS/IPsec / 처리(Use): TEE 등. **TEE가 저장 데이터 암호화를 자동 제공하지는 않음**.

### 7. 실제 적용 사례 — 가상 시나리오와 구분

- **Microsoft ElectionGuard — 동형암호**: 암호화된 투표 집계와 검증을 지원하는 선거 시스템. 실제 시험 작성 시 '개별 복호화 없는 투표 집계'를 중심으로 기술.
- **Apple — 차분 프라이버시**: 이용 통계 수집에 적용 사례 공개.
- **영국 NHS England — 합성데이터**: 인공 환자 데이터 생성·평가 **프로젝트**. 전면 상용 운영이라고 쓰지 않기.
- **Google Gboard — 연합학습**: 기기별 로컬 학습 업데이트 집계를 활용한 키보드 기능 개선.

※ 위 사례는 학습 시 조사한 실제 사례 요약. 시험에서 기업명·적용 기능을 쓰되, 연구·실증을 상용 도입으로 과장하지 않기. 일반적인 '병원 A/B 공동 학습', '클라우드에 환자 통계 위탁'은 **이해용 가상 시나리오**로 구분.

## Ⅳ. 암기 우선순위

**[최우선 암기]**
- PET 정의 + 4분류 정확한 명칭: **데이터 난독 처리 도구 / 암호화된 개인정보 처리 / 연합 및 분산 분석 / 데이터 책임 도구**.
- HE = 암호문 연산 / DP = 개인 영향 제한·ε↓ 보호↑ / SDG = 인공 데이터 / MPC = 비밀 공동 계산 / FL = 로컬 학습 / ZKP = 비밀 없이 사실 증명 / TEE = 처리 중 데이터 보호.
- HE·DP·SDG 3기술 비교의 **원리·보호 시점·한계·적용 사례**.
- ZKP의 완전성·건전성·영지식성.

**[원리 이해]** HE 내부 잡음과 DP 잡음 차이; FL과 MPC 차이; 합성데이터 과적합·재식별; TEE와 TDE 차이; DP ε의 의미.

**[별도 문제 대비]** HE PHE/SHE/FHE·스쿼싱·부트스트래핑, MPC 상세 알고리즘, ZKP 상세 분류, 가명정보 처리 5단계.

※ 기존에 확정한 암기 두음은 이 대화에서 확인되지 않아 새 두음을 임의 확정하지 않음.
