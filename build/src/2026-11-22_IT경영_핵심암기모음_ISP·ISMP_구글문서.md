# 핵심암기 모음 — IT경영·PM: ISP·ISMP (2026-11-22, GPT)

원본: 드라이브 05_암기노트 › 핵심암기 모음 (구글 문서) — ISP·ISMP 구역만 옮김

## 1. ISP 정의
경영전략 연계 / 정보화 비전·전략 / 목표모델 / 통합이행계획

정의: 경영전략과 정보화 목표를 연계하여 정보화 비전, 목표모델 및 통합이행계획을 수립하는 계획 기법.

## 2. ISP 5단계
환경분석 → 현황분석 → 정보화 비전·전략 수립 → 목표모델 설계 → 통합이행계획 수립

- 단계별 핵심어: ① 외부환경·정책·기술동향 ② As-Is·문제점·개선과제 ③ 정보화 목표·전략과제 ④ To-Be 업무·응용·데이터·기술·보안 구조 ⑤ 우선순위·일정·투자비·기대효과
- 대표 산출물: 환경분석서 / 현황분석서 / 정보화 전략 / To-Be 목표모델 / 통합이행계획서
- 기존 확정 두음: 환현정목통

## 3. ISMP 정의
특정 정보시스템 구축 / 업무·정보기술 요구사항 / 상세 요건 정의 / 구축사업 이행방안 / RFP

정의: 특정 정보시스템의 구축을 위해 업무·기술 요구사항을 구체화하고 구축사업 이행방안을 수립하는 계획 기법.

## 4. ISMP 5단계
프로젝트 착수 및 참여자 결정 → 정보시스템 방향성 수립 → 업무 및 정보기술 요건 분석 → 정보시스템 구조 및 요건 정의 → 정보시스템 구축사업 이행방안 수립

- 단계별 핵심어: ① 수행조직·계획 ② 목적·범위·방향 ③ 업무·IT 현황·요건 조사·분석 ④ 아키텍처·요건 명세·추적성 ⑤ 구축비·발주전략·RFP
- 대표 산출물: 프로젝트 계획서 / 방향 정의 / 요건 분석 결과 / 구조·요건 정의서 / 구축사업 이행계획·RFP
- 기존 확정 두음: 착방정요이

## 5. 핵심 비교
ISP=전략·목표모델·통합이행계획 / ISMP=구축 대상 상세 요구사항·이행방안; 공공사업은 준비도·요구사항 구체화에 따라 유형 선택, 반드시 ISP→ISMP 순서가 아님. ISP에서도 RFP 작성 가능.

헷갈리는 짝: ISP ③=정보화 비전·전략 수립(무엇을 추진?) / ISMP ③=업무 및 정보기술 요건 분석(특정 시스템에 무엇이 필요?). ISP ④=To-Be 목표모델 설계 / ISMP ④=특정 시스템 구조·요건 상세 정의. ISMP 요건 분석(조사·도출) vs 요건 정의(구조화·명세화).

## 6. 공통가이드
ISP·ISMP 수립 절차와 산출물 검토 기준 / 사업 타당성·실현 가능성·규모 적정성 / 공공사업 계획 품질·투자 효율성. 제6판 변경사항 전체 암기보다 실제 단계별 활동·산출물 우선.
