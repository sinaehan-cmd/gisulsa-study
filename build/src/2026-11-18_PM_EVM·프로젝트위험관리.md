## Ⅱ. 개념 이해
### EVM (성과관리)
프로젝트는 지금까지 돈을 얼마나 썼는지만 보면 성과를 판단할 수 없다. 계획상 어디까지 진행해야 했는지(PV), 실제 완료한 작업이 계획상 얼마의 가치인지(EV), 실제 얼마를 지출했는지(AC)를 비교해 **일정과 원가를 함께 관리**한다.

### 위험관리
아직 발생하지 않은 불확실한 사건이 일정·원가·범위 등에 미칠 영향을 식별하고, 가능성과 영향을 분석해 대응한다. 대응 4전략은 '위험을 없애기(회피)', '다른 주체에게 부담 이전(전가)', '가능성이나 영향 줄이기(완화)', '감수하고 대비(수용)'로 이해한다.

### 혼동 교정
- **EVM** = Earned Value Management: 프로젝트 일정·원가 성과관리.
- **EMV** = Expected Monetary Value: 위험 사건의 확률 × 손익을 합한 기대금전가치.
- **SV = EV − PV**는 완료 작업의 가치 차액이며 **일정 지연률(%)이 아님**. 일정 효율의 비율은 SPI로 본다.
- 의사결정나무 첫 문항은 문제 제목에서 정답이 노출되었으므로 해당 응답을 독립 인출로 인정하지 않음.

## Ⅲ. 기술사 답안 핵심
### 1. EVM 정의·구성요소
**계획가치·획득가치·실제원가를 통합 비교하여 프로젝트 일정·원가 성과를 관리하는 기법.**

| 구분 | 의미 | 계산·해석 |
|---|---|---|
| PV (Planned Value) | 기준일까지 계획된 작업의 예산가치 | 일정 기준 |
| EV (Earned Value) | 실제 완료한 작업의 예산가치 | 획득 실적 |
| AC (Actual Cost) | 실제 투입 비용 | 원가 실적 |
| SV (Schedule Variance) | 일정 편차 | **EV−PV**; 음수면 지연 |
| CV (Cost Variance) | 원가 편차 | **EV−AC**; 양수면 원가 효율 양호 |
| SPI (Schedule Performance Index) | 일정 성과지수 | **EV/PV**; 1 미만이면 일정 지연 |
| CPI (Cost Performance Index) | 원가 성과지수 | **EV/AC**; 1 초과면 원가 효율 양호 |

**사례:** SV=-20, CV=+10 → 일정은 계획 대비 지연, 원가는 완료한 작업의 가치 대비 효율 양호. 단위가 별도로 주어지지 않으면 금액·비율 임의 가정 금지.

### 2. 프로젝트 위험관리 정의·7단계
**프로젝트 목표에 영향을 미치는 불확실성을 식별·분석하고 대응·감시하는 관리 프로세스.**

```text
위험관리 계획 → 위험 식별 → 정성적 위험 분석 → 정량적 위험 분석
             → 위험 대응 계획 → 위험 대응 실행 → 위험 감시
```

| 단계 | 핵심 역할 |
|---|---|
| 위험관리 계획 | 방법론·책임·기준 수립 |
| 위험 식별 | 위험목록·원인·영향 파악 |
| 정성적 분석 | 확률·영향도에 따른 우선순위 |
| 정량적 분석 | 금전·일정 등 수치적 영향 평가 |
| 대응 계획 | 회피·전가·완화·수용 등 전략 선정 |
| 대응 실행 | 책임자 중심 대응책 수행 |
| 감시 | 신규·잔여 위험·조치효과 추적 |

### 3. 부정적 위험 대응전략
| 전략 | 의미 | IT 프로젝트 예 |
|---|---|---|
| 회피 | 위험 원인 제거 | 위험한 신규 기술 채택 범위 철회 |
| 전가 | 위험 부담 제3자 이전 | 계약·보험·외주로 비용상 위험 이전 |
| 완화 | 발생확률·영향 감소 | 이중화, 사전 성능시험 |
| 수용 | 위험을 감수하고 대비 | 예비비 확보, 비상계획 마련 |

※ 사례는 이해를 위한 보충 설명이며 학생의 실제 인출 답변이 아님.

### 4. 정량 위험분석
- **EMV:** 각 결과의 `발생확률 × 금전적 손익`을 합산한 기대금전가치. GPT 기록상 학생이 공식과 사례 결과 600만원을 맞힘.
- **몬테카를로 시뮬레이션:** 확률분포에 기반한 반복 모의실험으로 일정·비용 결과의 분포를 추정.
- **민감도 분석·토네이도 차트:** 입력 변수가 결과에 주는 영향의 크기 비교. 막대가 짧으면 영향이 상대적으로 작음.
- **의사결정나무:** 대안별 확률·손익을 가지치기해 기대값 비교.
- **영향관계도:** 의사결정(□), 불확실성(○), 결과(◇) 간 영향 표현.

## Ⅳ. 암기 자료
- EVM 3값: **PV·EV·AC**.
- 성과 편차: **SV=EV−PV, CV=EV−AC**; 지수: **SPI=EV/PV, CPI=EV/AC**.
- 위험관리 7단계: 계획 → 식별 → 정성 → 정량 → 대응계획 → 대응실행 → 감시.
- 위험 대응: **회피·전가·완화·수용** (기억 완성 미확인).
- 정량 기술: **몬테카를로·민감도·영향관계도·의사결정나무·EMV**.
- **EVM ≠ EMV**.
- 이 토픽의 확정 두음이 장부에서 확인되지 않았으므로 임의 생성·변경하지 않음.
