## Ⅱ. 개념 이해 및 질문
### 1. ISP와 BPR
- ISP: 조직의 경영전략을 지원하도록 정보화 목표·전략·이행계획을 수립.
- BPR: 기존 업무 프로세스를 근본적·급진적으로 재설계하여 비용·품질·서비스·속도의 획기적 성과 개선 추구.
- 학생이 앞선 학습에서 '잘못된 것을 전산화하면 잘못된 것이 더 빨라질 뿐'이라는 취지를 물었음. 요지는 기존의 비효율적 업무를 그대로 정보화하지 말고, 업무 혁신(BPR)과 정보화 계획(ISP)을 연계하라는 것.
- 초점: ISP = 정보화 전략·계획 / BPR = 업무 자체의 재설계. 순서가 반드시 고정되는 것은 아님.

### 2. IT 거버넌스와 ITSM
- IT 거버넌스: 경영목표와 IT를 연계하여 IT 의사결정·책임·가치·위험·성과를 통제하는 체계.
- ITSM: IT 서비스를 설계·전환·운영·개선하여 고객 가치와 서비스 품질을 관리하는 체계.
- 시험 비교: 거버넌스는 'IT를 왜·무엇을 위해 통제할까', ITSM은 '서비스를 어떻게 운영·개선할까'.
- 연계: 거버넌스 → 서비스 관리(ITSM) → 서비스 수준 약속(SLA) → 모니터링·개선.
- 학생은 IT 거버넌스 5영역을 '전자가위성'(전략연계·자원관리·가치제공·위험관리·성과측정)으로 말했고 COBIT과 ITIL을 비교 질문함. COBIT은 IT 거버넌스·관리 프레임워크, ITIL은 IT 서비스관리 모범사례. ISO/IEC 20000은 ITSM 요구사항 표준.

### 3. IT 아웃소싱 (중 — 핵심만)
**정의:** 핵심역량 집중과 비용 효율화를 위해 IT 업무의 일부 또는 전부를 외부 전문조직에 위탁하는 전략적 조달 방식.

**사람말 원리:** 회사가 모든 서버·애플리케이션·헬프데스크를 직접 운영하지 않고 전문업체에 맡긴다. 하지만 외부에 맡겨도 발주기업의 관리·보안·서비스 책임이 자동으로 사라지지는 않는다.

| 분류 기준 | 유형 | 의미 |
|---|---|---|
| 범위 | 전체형 / 선택형 | IT 업무 대부분 또는 특정 기능만 위탁 |
| 수행 위치 | 온사이트 / 오프사이트 | 고객사 현장 / 외부 사업장 |
| 위탁 업무 | ITO / BPO / KPO | IT / 업무 프로세스 / 지식집약 업무 |
| 조달 방식 | 클라우드 활용 | 외부 클라우드 서비스 조달(위의 분류축과 다름) |

**장점:** 핵심역량 집중, 규모의 경제·비용 효율화, 전문성·신기술 접근, 운영 유연성.

**위험:** 공급자 종속(Lock-in), 보안·정보유출, 품질 통제 저하, 책임·계약 분쟁, 이관·전환 비용.

**관리:** SLA(고객↔서비스 제공자) / OLA(서비스 제공조직 내부 팀 간 합의) / UC(외부 하위 공급자와의 계약), Penalty·Incentive, SIP(Service Improvement Plan), Annual Reset(계약 지표·목표 주기적 재설정), Exit Plan(해지·데이터 반출·전환 계획).

| 핵심 관리 요소 | 시험에 쓸 한 줄 |
|---|---|
| SLA | 품질 지표·측정·보고·책임·보상 합의 |
| OLA | 내부 지원조직 간 역할·지원 수준 합의 |
| UC | 하위 외부 공급업체와 이행 계약 |
| SIP | 품질 미달 원인 분석 및 서비스 개선계획 |
| Annual Reset | 연차별 지표·목표·계약 조건 재검토 |
| Exit Plan | 계약 종료·업체 교체 시 서비스 연속성 보장 |

**유형 관련 주의:** '클라우드'는 전체형/선택형, 온사이트/오프사이트와 같은 한 차원의 분류가 아님. 클라우드도 외부서비스 이용/조달의 한 형태일 수 있음.

**시험 연결:** 123회 4교시의 출제 소문항은 아웃소싱 유형 / SLA·OLA / Penalty·Incentive·SIP·Annual Reset. 129회 4교시는 클라우드 아웃소싱의 요구사항 / CSP 위험관리 / 대응방안.

## Ⅷ. IT-ROI·IT 투자분석 (상)
### 원리 및 정의
- ROI: IT 투자비 대비 순편익을 측정하여 투자 경제성을 평가하는 재무적 지표. ROI = (총편익 − 투자비용) / 투자비용 × 100(%). 1억 투자→1.5억 총편익이면 50%. 일반 단순 ROI는 시간가치 미반영.
- NPV: 미래 순현금흐름을 현재가치로 할인하고 초기 투자비용을 차감하는 투자평가 기법. NPV = Σ[CF_t/(1+r)^t] − I_0. CF_t=기간별 순현금흐름, r=할인율, I_0=초기 투자비용. NPV>0 투자 타당, =0 요구수익률 충족, <0 부적합. 미래 현금흐름 현재가치>초기 투자비용과 NPV>0을 구분.
- IRR: NPV를 0으로 만드는 할인율. 통상적 투자 현금흐름에서 IRR>요구수익률이면 타당. NPV는 요구수익률을 정해 금액을 계산, IRR은 사업 자체의 내재적 수익률을 계산. 1억 투자→1년 후 1.1억 회수 시 IRR 10%; 회사 요구 15%면 5%p 부족. 100만원→121만원 회수 시 1년/2년 ROI는 둘 다 21%, IRR은 21%/10%.
- PP(Payback Period): 초기 투자비용을 회수하는 데 소요되는 기간. 매년 순현금흐름 일정 시 초기 투자비용/연간 순현금흐름. 1억/2천만원=5년. 단순 PP는 시간가치와 회수 이후 현금흐름 미반영. 회수 전 추가 비용은 순현금흐름에 포함 가능. 할인회수기간법(DPP)은 시간가치 반영.
- TCO(Total Cost of Ownership): IT 자산 도입부터 운영·유지보수·폐기까지 발생하는 직·간접 비용 종합 산정. 구매/설치, 인력/전력/라이선스, 장애조치/업그레이드, 서비스 중단/생산성 저하, 데이터 이관/폐기. 동일 서비스 수준에서 비용 비교. ROI는 편익 대비 투자비, TCO는 생명주기 총비용.

### 시험용 비교표
| 구분 | ROI | NPV | IRR | PP | TCO |
|---|---|---|---|---|---|
| 평가 | 순편익률 | 순현재가치 | 내부수익률 | 회수기간 | 총비용 |
| 단위 | % | 금액 | % | 기간 | 금액 |
| 시간가치 | 미반영 | 반영 | 반영 | 미반영 | 방식에 따라 |
| 판단 | 높을수록 | 양수 | 요구수익률 초과 | 짧을수록 | 낮을수록 |
| 장점 | 산출 간편 | 가치 평가 | 수익률 비교 | 유동성 평가 | 비용 종합 |
| 한계 | 기간 미반영 | 할인율 의존 | 복수 IRR 가능 | 회수 이후 무시 | 편익 미평가 |

- 할인현금흐름법(DCF): NPV, IRR. 비할인 방식: 일반 ROI, PP. 비용 분석: TCO. 새로운 두음 확정 없음.

| 시간가치 반영 기법 | IRR, NPV | 정답 |
| NPV/IRR 판단 기준 | 미래 수익 현재가치/목표수익률 혼합 → 투자비, 회사 목표수익률 | IRR 정답, NPV>0 재교정 |
| 최종 5개 평가 기준 | ROI 투자비 대비 이익률, NPV 미래 이익 현재가치 변환, IRR NPV 0 할인율, PP 투자비 회수 시간, TCO 투자비 포함 유지 중 모든 비용 | 4개 정답·1개 부분 정답(NPV 초기 투자비 차감 누락). TCO 폐기 포함 보충 |

- 최종 평가: IT-ROI·IT 투자분석 구술 수준 2. 백지 작성·채점 없음. 반복 오답: NPV 현재가치 환산 후 초기 투자비 차감, NPV>0 기준, ROI 산식. PP 한계·ROI/IRR 시간가치 차이는 교정 후 성공. 다음 AI는 이 세 약점부터 무힌트 질문.

## Ⅸ. 모의고사 관련 메모
- 학생이 지난 모의고사 1교시 13문제·2교시 6문제 원문을 제시하고 출제 범위와 학습 범위의 괴리로 속상해함. 해설 이미지는 미확인. 실제 모의고사 답안 작성 또는 채점 없음.
- 인시던트 관리(신속 복구) vs 문제 관리(근본 원인 분석·재발 방지) 정의·비교표 및 서버 재기동/메모리 누수 사례를 짧게 설명했으나 학생은 기존 투자분석 학습을 이어가자고 요청. 독립 인출 미실시. 나머지 모의고사 토픽은 학습 완료로 기록하지 않음.
