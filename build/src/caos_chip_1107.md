# PART 1. 칩 비교

## 1-1. CPU vs GPU vs TPU vs NPU ★
> 기출: 138 정관 2교시(GPU vs TPU) · 140·134 컴시응 1교시(NPU) · 137(GPU)

| 비교 | CPU | GPU | TPU | NPU |
|---|---|---|---|---|
| 목적 | 범용 · 제어 | 그래픽 · 범용 병렬 | 대규모 AI 학습·추론 | 온디바이스 AI 추론 |
| 코어 | 소수 고성능 (수십 개) | 수천 개 단순 코어 | 행렬 연산 유닛 (MXU) | MAC 어레이 |
| 구조 | 순차 · 분기 예측 강함 | SIMT (SIMD 계열) | **시스톨릭 어레이** | 데이터플로우 |
| 비유 | 박사님 몇 명 | 초등학생 수천 명 | 행렬곱 전용 공장 | 곱셈·덧셈 소형 공장 |
| 정밀도 | FP64 | FP32 · FP16 | BF16 · INT8 | INT8 · INT4 |
| 유연성 | 최고 | 높음 (CUDA) | 낮음 (텐서 전용) | 낮음 |
| 전력 효율 | 낮음 | 보통 | 높음 | **매우 높음** |
| 메모리 | DDR | HBM (게이밍은 GDDR) | HBM | LPDDR · 온칩 SRAM |
| 예 | Intel · AMD | NVIDIA H100 · B200 | Google TPU | 스마트폰 AP · 자동차 |

- CPU = 똑똑하지만 적다 / GPU = 단순하지만 많다 / TPU = 행렬곱만 / NPU = 저전력 추론만
- AI 연산 = 거의 다 **곱하고 더하기 (MAC)** → 행렬곱 전용 칩이 유리

## 1-2. FPGA vs ASIC (+ GPU)
> 기출: 140(ASIC) · 학원 단골

| 비교 | GPU | FPGA | ASIC |
|---|---|---|---|
| 개념 | 범용 병렬 프로세서 | 회로를 **다시 짤 수 있는** 칩 | 특정 용도 **전용 고정** 칩 |
| 유연성 | 높음 | 중간 (재구성 가능) | 없음 (고정) |
| 성능·효율 | 높음 | 중간 | **최고** |
| 개발 비용 | 없음 (구매) | 낮음 | **매우 높음** (설계·생산) |
| 개발 기간 | 짧음 | 짧음 | 김 |
| 적합 | 범용 AI 학습 | 시제품 · 소량 · 통신 | 대량 양산 (TPU · NPU · 채굴기) |

- **TPU · NPU는 ASIC의 한 종류**

## 1-4. 기타 칩 이름표
| 이름 | 한 줄 |
|---|---|
| CISC vs RISC | 복잡 명령어·코드 짧음 (x86) vs 단순 명령어·파이프라인 유리 (ARM) |
| RISC-V | 오픈소스 RISC 명령어 집합, 라이선스 무료 |
| 칩렛 | 큰 칩 하나 대신 작은 칩 여러 개를 패키지로 조립 |
| TPM | 키 생성·저장과 무결성 측정을 하는 하드웨어 보안 칩 (132 정관 1교시) |
| 폴락의 법칙 | 코어를 2배 키우면 성능은 √2배 → 멀티코어로 전환 |

# PART 2. 메모리 비교

## 2-3. 메모리 벽 해결 3갈래: HBM vs CXL vs PIM ★
> 기출: 140 컴시응 3교시 · 129 컴시응 2교시(CXL) · 129·131(PIM·PNM) · 셀테 8번

| 비교 | HBM | CXL | PIM / PNM |
|---|---|---|---|
| 해결 대상 | **대역폭** 부족 | **용량** 부족 · 자원 낭비 | **데이터 이동** 비용 |
| 방법 | 적층으로 길을 넓힘 | PCIe로 외부 메모리 연결·공유 | 메모리 안·옆에서 계산 |
| 한계 | 비쌈 · 공급 부족 · 발열 | 지연 증가 | 연산 단순 · 표준 부재 |
| 예 | HBM3E · HBM4 | CXL 메모리 확장기 · CXL 3.0 스위치 | 삼성 HBM-PIM · CXL-PNM |

**PIM vs PNM**
| 비교 | PIM (In) | PNM (Near) |
|---|---|---|
| 연산 위치 | 메모리 셀·뱅크 **안** | 메모리 **옆** (베이스 다이·버퍼·CXL 컨트롤러) |
| 데이터 이동 | 최소 | 적음 |
| 연산 능력 | 단순 (곱셈·덧셈) | 상대적으로 복잡 |
| 구현 난이도 | 높음 | 낮음 |
| 예 | 삼성 HBM-PIM · SK하이닉스 AiM | 삼성 CXL-PNM · AXDIMM |
