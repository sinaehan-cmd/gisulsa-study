# 기술사 공부 저장소 (정보관리기술사)

Claude가 매일 공부한 내용을 모아 **암기노트 앱**을 새로 만들어 여기에 저장해요.

## 바로 쓰기
- `app/암기노트_최신.html` → 내려받아 크롬으로 열기 (📖 읽기 → 📌 키워드판 · 🙈 가리기 · 👁 초간단/간단/길게 · ▸자세히)
- 진도(정원)는 브라우저에 저장돼요. 새 버전을 열어도 진도와 내가 고친 카드는 그대로예요.

## 폴더
| 폴더 | 내용 |
|---|---|
| `app/` | `암기노트_v18_원본.html`(바탕) · `암기노트_최신.html`(매일 새로 만든 것) |
| `build/kb_data.py` | 키워드판 데이터: 토픽마다 핵심어 · 두음 · 키워드 표 · ❌ 틀린 것 |
| `build/detail_map.py` | ▸자세히에 붙일 정리 노트 위치 |
| `build/src/` | 정리 노트 원본 MD (GPT·Claude 학습 기록, 교재 요약) |
| `notes/` | 날짜별 변경 기록 |

## 다시 만들기
```
pip install markdown
python3 build/build.py app/암기노트_v18_원본.html app/암기노트_최신.html v19-YYYYMMDD
```

## 규칙 (Claude·GPT)
- 두음 원본은 구글 시트 '기술사 공부관리' → 두음 탭. 확정 두음은 바꾸지 않기.
- 앱 HTML을 손으로 고치지 않고 `kb_data.py`·`src/`만 고친 뒤 다시 만들기.
- 카드 기준: "그 토픽의 기출 방향 전부에 답할 수 있나" (짧게 줄이지 않기).

## 앱에서 외운 결과 알리기
- 📖 읽기 화면의 **📋 오늘 결과 복사** → Claude나 GPT 채팅에 붙여넣기
- 받은 AI는 그 글을 시트 '일지' 탭에 한 줄로 남긴다 (D: '암기노트 결과', G: 붙여넣은 글 그대로)
- 밤 저장 작업이 그 줄을 읽어 몰라·애매 카드를 다음 날 먼저 볼 카드로 고른다

## 학원 중요도
- 카드 제목을 `build/src/학원토픽.csv`(학원 토픽 747개)와 맞춰 최상·상·중·하 배지를 단다. 못 찾으면 배지 없음
- 틀린 배지는 `kb_data.py`에서 그 카드에 `imp='상'`처럼 직접 적어 고친다

## 🔄 새 내용 받기 (앱을 다시 받지 않아도 됨)
- 앱 위쪽 🔄 버튼 → 깃의 `app/update.json`을 가져와 새 카드·보강을 합친다. 앱을 열 때 하루 한 번은 자동으로 확인한다.
- `update.json`은 build.py가 앱과 같이 만든다. 반드시 앱과 함께 커밋한다.
- 앱 기능(버튼·화면)이 바뀐 날만 html을 다시 받으면 된다.
